# Trading Helper

Trading signals app for Android 12 (API 31).

## Features
- 8 indicators: RSI, MACD, Bollinger Bands, Stochastic, Williams %R, ADX, EMA
- Data sources: Binance API, Yahoo Finance
- Price chart (Kivy Canvas)
- Martingale calculator
- Pure Python — no numpy/pandas/matplotlib

## Build
Push to GitHub → Actions tab → download APK artifact.
